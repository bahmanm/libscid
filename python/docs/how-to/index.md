# How-To Guides

This section contains recipe-oriented guides demonstrating how to accomplish specific tasks with the `libscid` Python bindings.

Each guide assumes familiarity with the foundational concepts introduced in the [Tutorials](../tutorials/quickstart.md) and focuses on practical problem solving.

---

## 1. Available Recipes

- [Parse and Serialise PGN](parse-and-serialise-pgn.md): Parse PGN movetext, configure formatting options, and attach custom metadata tags.
- [Navigate and Edit Move Trees](navigate-and-edit-trees.md): Traverse branching variation trees, append sub-lines, and attach comments or NAG glyphs using immutable cursors.
- [Filter and Search Databases](filter-and-search-databases.md): Build multi-criteria queries, combine filter bitsets with boolean algebra, and paginate sorted game indices.
- [Stream Movetext Events](stream-movetext-events.md): Process hierarchical movetext event streams with structural pattern matching.
- [Adjudicate Tournament Draws](adjudicate-draws.md): Evaluate threefold repetition and fifty-move rule claims using the tournament arbiter.
